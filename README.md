# Microcontrollers
## lab 1
#### Лабораторна робота полягає в реалізації алгоритму засвічування трьох світлодіодів з можливістю керування швидкістю блимання через веб-сторінку. Для цього використовувався мікроконтролер ESP8266, кнопка для ініціювання зміни інтервалу блимання та створення веб-сторінки для контролю.
